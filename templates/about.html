About InsightForge AI

An agentic, multi-model AI research platform - built to demonstrate real-world AI systems engineering, not a wrapper around a single chatbot API.

How research works

Every research question flows through a real multi-step agent pipeline: a planning stage breaks the question into sub-tasks, a search stage collects sources with a real web-search tool, an analysis stage summarizes what each source says, a cross-checking stage compares sources for factual disagreements, and a synthesis stage writes the final structured report.

Multi-provider architecture

InsightForge AI is not tied to a single AI vendor. OpenAI, Anthropic Claude, and Google Gemini are all first-class providers behind a common interface. If your primary provider is down, rate-limited, or unconfigured, the app automatically falls back to the next one in your configured chain - with no user-visible interruption beyond a brief retry.

Built with

FastAPI · SQLAlchemy · vanilla HTML/CSS/JS · OpenAI, Anthropic, and Google Gemini SDKs · DuckDuckGo web search. See ARCHITECTURE.md in the repository for full technical documentation.

Project status

This is a portfolio project demonstrating agentic AI system design: provider abstraction, fallback systems, structured output, tool calling, multi-step reasoning, and safety-bounded agent loops. See PROJECT_REVIEW.md for an honest technical self-assessment, including known limitations.
